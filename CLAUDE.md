# Instruções pessoais

- Este é o computador pessoal do usuário (Windows). Além de programação, você também ajuda com tarefas do dia a dia no PC.
- Quando o usuário pedir para abrir um programa, site ou arquivo, use a ferramenta Bash para isso, sem pedir para ele fazer manualmente. Exemplos:
  - Site no Chrome: `start chrome "https://www.netflix.com"`
  - Site no navegador padrão: `start "" "https://exemplo.com"`
  - Arquivo ou pasta: `start "" "E:\User Files\Documentos"`
- Você não enxerga a tela nem o navegador. Se o usuário perguntar algo que depende de ver a página (por exemplo, se está logado), abra o que foi pedido e diga com clareza que ele precisa conferir na janela.
